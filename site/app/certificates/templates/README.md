# Certificate Template Assets

Place the five exact user-approved PNG certificate templates in this folder using these filenames:

- `ielts-template.png`
- `science-template.png`
- `olympiad-template.png`
- `english-template.png`
- `math-template.png`

These files are the final certificate artwork. The application must overlay dynamic fields only.

Do not redraw or imitate these certificate designs in CSS.
See `docs/CERTIFICATE_IMPLEMENTATION_SPEC.md`.
